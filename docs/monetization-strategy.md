# 오른스코어 수익화 전략 (v1)

> 작성: 2026-06-13 · 외부 프로덕트 리뷰(6.5/10) + 한국 규제 환경 반영
> 상태: **기획 단계** — 결제 연동 전. 방향 합의용 문서.

---

## 0. 한 줄 요약

> **지금은 과금하지 않는다.** 백테스트로 점수가 검증되기 전 "점수 자체"를 팔면 사용자가 성과를 요구하게 되고, 개별 투자 조언을 유료로 팔면 규제(투자자문업) 리스크가 생긴다.
> 대신 **"시간 절약 + 변화 알림"이라는 도구 가치**를 유료로 설계하고, 지금은 **무료로 사용자·신뢰를 쌓으며 유료 대기자(waitlist)만 모은다.**

---

## 1. 핵심 원칙

1. **유료 가치는 "점수"가 아니라 "시간 절약과 알림"이다.**
   - "이 종목이 좋은가?"(❌ 검증·규제 리스크) → "내가 보는 종목에 변화가 생기면 놓치지 않게 해준다"(✅ 명확한 도구 가치).
2. **백테스트 신뢰가 쌓이기 전엔 점수를 전면에 유료화하지 않는다.** (현재 점수 = 실험 지표)
3. **개별 종목 매수·매도 '추천/조언'은 유료로 팔지 않는다.** (아래 법무 가드레일)
4. **무료의 폭을 넓게.** 탐색·기본 지표·공시 목록은 계속 무료 → 유입·SEO·신뢰.

---

## 2. ⚠️ 법무 가드레일 (가장 중요 — 먼저 읽기)

**2024-08-14 시행 자본시장법/시행령 개정**으로 유사투자자문업 규제가 강화됐다. 핵심:

- **단방향 · 불특정다수 · 개별성 없는 조언** → 유사투자자문업(신고제) 영역.
- **SNS·오픈채팅 등 양방향 채널 + 유료 회원제로 개별성 있는 조언** → **유사투자자문업이 아니라 '투자자문업'으로 규율** (정식 인가·자기자본·전문인력 필요. 훨씬 무거움).
- 손실보전 약정 금지, 표시·광고 규제 도입.

### 오른스코어에 적용되는 안전선

| 해도 되는 것 (도구·정보) | 위험한 것 (자문 소지) |
|---|---|
| 종목 점수·지표·공시를 **불특정다수에게 동일하게** 제공 | 사용자 **보유 종목에 맞춘 개별 조언** |
| 관심종목에 **공시/점수변화 발생 사실**을 통지(정보 전달) | **"지금 매수/매도하세요"** 식 개별 시점 신호 |
| 조건 저장·CSV·업종 비교 등 **분석 도구** 판매 | **목표가·매수가·손절가** 제시 |
| "투자 추천 아님" 고지 + 도구로 포지셔닝 | 양방향 **유료 1:1 투자 상담** |

> **결론**: 유료 기능은 "개인화된 조언"이 아니라 **"개인화된 정보 도구"**로 설계해야 한다.
> 알림도 "X 종목에 자기주식취득 공시 발생"(정보)은 OK, "X 종목 매수 타이밍"(조언)은 위험.
> **실제 유료 출시 전 반드시 자본시장법 전문 변호사 검토.**

## 3. 무료 / 유료 티어 구조 (제안)

### 🆓 무료 (Free) — 유입·신뢰
- 오늘의 후보 종목(상위 일부) · 오늘의 브리핑
- 138개 종목 탐색 + 기본 필터 + 질문형 프리셋
- 종목 상세(점수·차트·초보자 해석·공시 목록)
- 관심 종목 **5개**, 비교 **2개**
- AI 분석 **월 3회**

### 💎 유료 (Pro) — "시간 절약 + 알림" (출시 예정)
모두 **도구·정보 전달** 성격으로 설계 (개별 조언 ❌):
- **관심 종목 무제한** + **변화 알림**(공시 발생·점수 급변·조건 충족 *사실* 통지)
- **조건 저장** + 저장 조건 결과 변화 알림
- **장기 점수 기록**(전체 히스토리) · **업종 대비 비교**
- **백테스트**(검증 완료 후) · **CSV 내보내기**
- **나만의 데일리 브리핑**(관심군 요약 메일)
- AI 분석 무제한 또는 크레딧

> 핵심 후크: **알림**. 리뷰어도 "알림이 백테스트보다 재방문율에 더 큰 영향"이라 지적.

## 4. 가격 (가설 — 검증 필요)

- 국내 프리미엄 주식 정보/툴: 대략 **월 1만~5만 원대**가 흔함(서비스별 편차 큼, 정확치는 경쟁사 확인 필요).
- 오른스코어 포지션: 리딩방(고가·고위험)과 무료 앱 사이의 **"가벼운 데이터 도구"**.
- 1차 가설: **월 4,900~9,900원** (연간 할인). 베타는 **얼리버드 50% 또는 무료 베타** 후 유료 전환.
- ⚠️ 실제 가격은 waitlist 규모·설문·경쟁사 가격 확인 후 확정.

---

## 5. 출시 로드맵 (단계적)

1. **지금 (0~1개월)**: 요금제 페이지(`/pricing`)에 무료/유료(출시 예정) 명시 + **"알림 출시되면 알려주세요" waitlist 이메일 수집**. 결제 없음. → 수요 검증.
2. **1~2개월**: 무료 사용자·관심종목 데이터 축적. 알림(공시·점수변화) cron 안정화. 백테스트 신뢰 보강.
3. **2~3개월**: **유료 베타**(얼리버드, 소수). 알림·조건저장·CSV부터. 결제는 PG/구독(토스페이먼츠 등) 연동.
4. **검증 후**: 백테스트 공개 완료 → 정식 유료, 가격 확정.
