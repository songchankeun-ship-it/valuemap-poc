## 현재 측정과 오너 입력

집계는 기본 비활성 상태로 제공된다. 로컬에서 미설정 상태와 모의 집계만 확인했다. 실서비스의 신규 집계·행동·가입 실측치는 아직 확인하지 않았고, Google Search Console의 검색 노출·클릭 기준선만 오너 계정에서 확인했다. 운영 트래픽의 7일·30일과 콘텐츠 패킷의 14일은 KST 달력 기준이며 당일 일부를 포함한다.

1. **집계 스키마 승인 및 적용** — 오너가 [SQL 패킷](sql/growth_aggregate.sql)과 [활성화 런북](ornscore-growth-aggregate-owner-runbook.md)을 검토한다. 개인정보 고지·필요한 동의와 인프라 로그/APM의 요청 정보 미보존을 확인한다. 승인 후 스테이징 DB에 스키마 소유자로 연결하도록 설정한 뒤, 저장소 루트에서 `psql -X -v ON_ERROR_STOP=1 -f docs/sql/growth_aggregate.sql`을 1회 실행한다. 연결 정보는 승인된 로컬 PostgreSQL 연결 설정을 사용한다. SQL에 트랜잭션이 포함돼 있다. 전용 로그인에는 연결 및 `ornscore_growth_runtime` 권한만 부여하고 테이블·계정 데이터 직접 접근 및 익명/API 역할의 함수 실행이 차단됐는지 확인한다. 서버 측 `ORNSCORE_GROWTH_DATABASE_URL`, 정확한 HTTPS `ORNSCORE_GROWTH_ORIGIN`, `ORNSCORE_GROWTH_ENABLED=1`로 새로 빌드한 스테이징에서 빈 집계, 승인된 이벤트 증가, 읽기 실패 및 운영 화면 제외를 확인한다. 30일 보존·삭제 및 중지 절차는 런북을 따른다.
2. **Search Console 확인 완료** — 2026-11-19 `contact@ornscore.com` 계정에서 `sc-domain:ornscore.com` 접근을 확인했다. 최근 3개월은 클릭 2회, 노출 568회, CTR 0.4%, 평균 게재순위 8.6이다. 클릭은 `/topics/high-roe-stocks`와 `/compare`에서 각 1회 발생했다. `/disclosures`는 노출 197회·클릭 0회, `/today`는 노출 143회·클릭 0회라 제목·설명과 검색 의도 개선을 우선 측정한다. 색인은 70개, 미색인은 125개이며 그중 100개는 발견 후 미크롤링, 7개는 크롤링 후 미색인이다. 기존 사이트맵은 166개 URL을 2026-07-20에 마지막으로 읽은 상태였고, 현재 177개 URL 사이트맵을 2026-11-19 재제출해 성공 응답을 확인했다. Google의 재처리를 기다린다. [기존 유입 계획](ornscore-organic-acquisition-plan-2026-11-17.md)
3. **측정 시작일과 발행 승인** — 오너가 수집 정상 여부, 집계 시작 KST 날짜, 발행할 초안 및 형식별 게시 횟수를 기록한다. 게시 횟수는 화면을 새로 고치면 초기화된다. 로컬 재인증에서는 SQL 적용, 환경 변경, 배포와 발행을 수행하지 않았다. 이후 오너 준비 단계에서 최신 사이트맵만 Search Console에 재제출했다.

## 14일 목표와 판단

정상 수집이 시작된 KST 날짜부터 14일을 같은 기준으로 비교한다. 이벤트 집계는 반복 행동을 포함하며 개별 사용자나 방문 경로를 연결하지 않는다.

| 지표 | 14일 목표 | 집계 기준 |
| --- | ---: | --- |
| 유효 유입 | 100건 | 검색 의도 토픽·비교 랜딩 또는 Threads·공유로 분류되는 공개 조회. 두 조건에 모두 해당하는 집계 행은 한 번만 합산한다. |
| 홈 → 상세 | 25% | 기존 Vercel 이벤트에서 `home_candidate_open`의 `slot=hero` 건수 ÷ `route_view_public`의 `routeKind=home` 건수. 이동 클릭 기준 대리지표이며 일별 집계에는 슬롯이 없다. 분모가 없으면 미산출이다. |
| 후속 행동 | 5건 | Threads의 형식별 비교 열기, 토픽에서 상세 열기, 관심종목 토글. 토글에는 해제도 포함되며 개별 게시물의 기여를 판별할 수 없다. |
| 신규 비오너 계정 | 5개 | 기존 `/admin/users`의 Supabase Auth 가입일시 기준으로 동일 기간의 가입자를 세고 오너·운영/검증 계정을 제외한다. |

수집 범위와 정상 동작을 확인하기 전에는 판단을 보류한다. 확인 후 같은 형식을 두 번 이상 게시했는데 유입이 0건이면 중단한다. 같은 14일 동안 해당 형식의 게시 횟수를 1회 이상 입력했고 유입과 지정 후속 행동이 각각 1건 이상이면 확대한다. 게시 횟수가 0회이거나 비어 있으면 집계값이 있어도 관찰한다. 집계에는 같은 유형의 다른 Threads 링크와 행동이 포함될 수 있다. 나머지는 관찰한다. 14일에 네 목표를 검토하고 검색 통계가 늦게 들어오면 30일에 다시 확인한다.
