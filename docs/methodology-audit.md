# 방법론 감사 — 단면(cross-sectional) 지표 구조

> 이 문서는 `scripts/methodology_audit.py` 가 현재 스냅샷에서 **결정적으로 재생성**합니다.
> 손으로 수정하지 마세요. 스냅샷이 같으면 출력도 동일합니다.

**이 감사는 현재 종합 점수를 검증하지 않습니다.** 단일 시점 스냅샷의 지표 구조(상관·기여·가중 대안·단일지표 제거)를 볼 뿐, 성과(백테스트)가 아닙니다.

- 스냅샷 기준일: `20260805` · 지표 버전: `2.4`
- 분석 유니버스: 138종목 (지표 결측 제외 0종목)
- 종합 점수 정의: compositeScore = mean(momentum, flow, value, volScore) (등가중).
- 분석 유형: **cross-sectional** (단면)
