## A. 약관 보강 항목 (유료 서비스 출시 전 확정 필요)

각 항목: **현재 상태 / 보강 필요 문구 방향 / 상용화 전 확정 필요**.
현재 `src/app/terms/page.tsx`는 제1~8조(성격·책임 한계·지재권 등)만 있고 **유료 결제 조항이 없다**. 아래는 결제 도입 시 추가할 항목이다.

| 항목 | 현재 상태 | 보강 필요 문구 방향(초안) | 상용화 전 확정 |
|---|---|---|---|
| **결제일** | 없음 | 구독 시작일 기준 정기 결제일 명시(예: 매월 동일자), 일할 계산 여부 | 필요 — 실제 PG/요금 정책 확정 후 |
| **자동갱신** | 없음 | 구독은 해지 전까지 자동갱신, 갱신 전 사전 고지 방식·시점 명시 | 필요 |
| **해지** | 없음 | 해지 신청 경로·해지 효력 발생 시점(다음 결제주기), 잔여 기간 이용 가능 여부 | 필요 |
| **환불** | 없음 | 환불 기준(이용일수 차감·결제수단별 처리기간), 단순변심/서비스 하자 구분 | 필요 — 콘텐츠/디지털 재화 환불 규정 검토 |
| **청약철회** | 없음 | 전자상거래법상 청약철회 가능 기간·예외(이미 제공된 디지털 콘텐츠), 고지 의무 | 필요 — 법정 요건 준수 확인 |
| **결제 실패** | 없음 | 결제 실패 시 재시도·유예기간·기능 제한/구독 정지 절차 | 필요 |
| **요금제 변경** | 부분 — `/pricing` 무료/Pro 경계 안내만 | 상위/하위 요금제 전환 시 적용 시점·차액 처리, 가격 변경 시 기존 구독자 사전 고지 | 필요 |
| **장애 보상** | 부분 — 제4·6조 "중단 책임 면책"만 있음 | 유료 구간 장애 시 보상 기준(SLA 또는 이용기간 연장 등) 또는 보상 범위 한계 명시 | 필요 — 면책과 보상의 균형 검토 |
| **유료 기능 변경 가능성** | 없음 | 유료 기능 구성은 사전 고지 후 변경될 수 있음, 중대한 불리한 변경 시 고지·해지권 | 필요 |

**조치**: `/terms`에 "유료 서비스 이용(출시 예정 · 초안)" 섹션을 추가해 위 항목이 출시 전 확정됨을 고지(이번 task에서 반영). 구속력 있는 금액·날짜는 명시하지 않는다.

## B. 개인정보 국외 이전 표 (역할별)

현재 `src/app/privacy/page.tsx` §5(위탁)·§5-1(국외 이전)에 반영되어 있으며, 본 표는 **역할별 단일 정리본**이다.

| 역할 | 제공자 | 이전 국가 | 항목 | 목적 |
|---|---|---|---|---|
| **인증 / 저장 제공자** | Supabase | 일본(Tokyo) | 이메일·계정 식별자·관심종목·비교·분석 기록 | 회원 인증, 데이터 저장·동기화 |
| **호스팅 제공자** | Vercel | 미국 | IP·접속 정보 | 웹 호스팅, 익명 통계 |
| **메일 발송 제공자** | Resend | 미국 | 이메일 주소 | 알림·waitlist 메일 발송 |
| **AI 처리 제공자** | Anthropic (Claude) | 미국 | AI 분석 시 전달되는 종목 데이터·질의 | AI 종합 분석 생성(입력은 모델 학습에 사용되지 않음) |
| **소셜 로그인** | Kakao | 대한민국(국내) | 카카오 계정 식별자·닉네임 | 소셜 로그인(선택 시) |

**보강 방향(초안)**
- 국외 이전 동의: 회원가입/AI 분석 실행 시점에 이전 국가·항목·목적·보유기간을 고지하고 동의받는 흐름 확인 필요.
- 이전 거부 시 대안: 해당 기능(AI 분석·알림) 미사용 또는 탈퇴로 거부 가능(현재 §5-1에 반영됨).
- **상용화 전 확정**: 위탁사 변경·추가 시 표 갱신, 보유기간을 §3과 일치시켜 유지.

## F. Task 66 (P1 follow-up) — 약관 안정화 메모 (2026-06-26)

이번 작업에서 `/terms`에 **현재(상용화 전) 확정 정책** 박스를 추가해, 지금 시점에 **이미 확정된 사실**(① 유료 결제 미제공·전 기능 무료, ② 매직링크/카카오 인증·비밀번호 미저장, ③ KRX·DART·Naver·yfinance 공개 데이터 출처·비자문 도구)만 안정 문구로 명시했다.

- **확정된 것**: 위 ①~③은 현재 제품 정책으로 사실이며 안정 문구로 표기 가능 → 이번에 firm 처리.
- **여전히 미확정(법무·사업 확정 필요)**: A항 결제·환불·청약철회·자동갱신·해지 효력 시점·장애 보상·정산 방식 — `/terms` 「유료 서비스 — 출시 전 확정 필요 항목」 블록에서 **계속 "초안·미확정"으로 표기 유지**(이번에 해결로 표시하지 않음).
- **법무 검토 상태**: 본 문서·약관 문구는 여전히 **변호사/사업 최종 검토 전 초안**이다. 이번 작업은 "현재 사실인 정책"만 안정화했을 뿐, 법적 검토 완료를 의미하지 않는다.
- **잔여 확정 리스크**: 결제(PG) 도입 시 전자상거래법·콘텐츠 환불 규정 대조, 국외 이전 동의 UX 구현, 위탁사 보유기간 정합성 — A~E항 그대로 미해결.
