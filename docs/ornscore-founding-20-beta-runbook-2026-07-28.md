# 오른스코어 첫 20명 통제 베타 운영안

## 목표

이번 베타의 목적은 방문자 수를 키우는 것이 아니라, 처음 온 사람이 아래 흐름을 실제로
끝낼 수 있는지 확인하는 것이다.

1. 아는 종목을 검색한다.
2. 종목 상세에서 점수의 이유를 이해한다.
3. 관심 종목에 저장하고 다시 돌아온다.
4. 가장 막힌 지점을 남긴다.

초대 주소는 `https://ornscore.com/beta?source=invite`다. 검색엔진에는 노출하지 않는다.

## 모집 범위

- 1차 인원: 20명
- 권장 구성: 주식 경험 적음 7명, 가끔 확인 7명, 자주 분석 6명
- 한 번에 20명을 모두 부르지 말고 5명씩 네 차례로 보낸다.
- 앞선 5명에서 치명적인 막힘이 나오면 다음 초대 전에 그 한 가지를 먼저 고친다.

## 초대 메시지

> 한국 주식 후보를 좁혀보는 작은 서비스를 만들었어요. 종목 추천을 받는 테스트가 아니라,
> 검색하고 점수 이유를 이해한 뒤 관심 종목으로 다시 돌아오는 흐름이 쓸 만한지 확인하고
> 싶습니다. 10분 정도 사용한 뒤 마지막에 가장 막힌 한 가지만 남겨주세요.
> https://ornscore.com/beta?source=invite

## 72시간 판단 기준

- `beta_start`: 초대 링크를 실제로 연 사람
- `beta_task_open`: 각 체험 단계로 이동한 사람
- `beta_task_complete`: 본인이 완료로 표시한 단계
- `beta_feedback_submit`: 의견 제출 시도
- `beta_feedback_result`: 저장 성공 또는 실패
- 일반 제품 퍼널: `search_result_open`, `watchlist_toggle`, `auth_cta_click`

절대 방문 수보다 이탈 위치를 본다. 5명 단위로 아래 한 가지만 결정한다.

- 시작도 하지 않음: 초대 문구 또는 첫 화면 문제
- 검색에서 이탈: 커버리지·검색어·결과 설명 문제
- 상세에서 이탈: 점수 근거와 다음 행동 문제
- 관심 저장에서 이탈: 저장 가치 또는 버튼 위치 문제
- 제출 실패: `data_reports` 저장 환경과 API 우선 점검

## 운영자가 볼 곳

- 익명 이벤트: Vercel Analytics에서 `beta_*`와 제품 퍼널 이벤트 확인
- 가입·저장 사용량: `/admin/users`
- 베타 자유 의견: `/admin/status`의 `베타 사용성` 분류
- 데이터 오류: 기존 `/admin/status`의 가격·재무·공시·점수 분류

베타 피드백 저장이 실패하면 화면에서 `contact@ornscore.com` 메일 전송으로 전환한다.
이름은 받지 않고 이메일은 답장이 필요한 사용자의 선택 입력만 받는다.
