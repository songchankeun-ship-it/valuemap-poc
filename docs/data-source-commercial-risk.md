# 데이터 소스 상용 이용 리스크 검토표

> **상태: 초안 · 상용화 전 법무 검토 필요.**
> 이 문서는 AI(Claude)가 코드베이스 사용 현황을 근거로 정리한 **실행 가능한 리스크 점검표**다.
> 법적 결론을 확정하지 않는다. "검토 필요"로 표시된 칸은 모두 상용 출시 전에 운영자/법무가 직접 확인해야 한다.
> 마지막 정리: 2026-06-25 (AI Center task 37, P2).

---

## 0. 사용하는 이유 / 범위

오른스코어는 공개된 한국 주식 시장 데이터와 자체 산식 점수를 제공하는 **데이터 탐색 도구**다(매수·매도 추천 아님).
현재 데이터는 로컬/배치 파이프라인에서 생성한 정적 스냅샷(`public/data/stocks.json`, `prices/*.json`, `backtest-result.json`)과 페이지 열람 시 라이브 조회(현재가·공시)를 혼합한다.

**핵심 리스크 요지**: 무료 데이터 출처라도 *개인/비상업 목적 한정* 또는 *재배포 금지* 조건이 흔하다. 상용(유료 구독) 전환 시 출처별 이용약관·라이선스를 개별 확인하고, 가능하면 **공식 유료 인터페이스**로 이전하거나 **대체 소스 / fallback**을 준비해야 한다.

## 2. 공통 조치 항목 (상용화 전)

1. **출처 표기 일관화** — 각 화면·`/status`에 데이터 출처와 "지연·참고용" 성격을 명시(현재 일부 반영됨).
2. **공식 경로 우선** — DART는 공식 API 유지, KRX는 공식 시세 라이선스 경로 확인, Naver/yfinance 의존은 축소·대체.
3. **재배포 회피** — 원문(특히 DART 공시)은 재호스팅하지 않고 원본 링크 연결 유지.
4. **한도·장애 대비** — 라이브 조회(현재가·공시) 실패 시 캐시/직전 데이터 fallback과 사용자 고지(`/status` "갱신 지연" 표시) 유지.
5. **상용 전 개별 약관 확인** — 위 표의 "검토 필요"는 출시 전 출처별 이용약관·라이선스를 개별 확인하여 결론을 채운다.

## 3. 미해결 / 후속 과제

- 각 소스의 **최신 이용약관 원문 대조**(이 문서는 코드 사용 현황 기반 추정이며 약관 원문 확정 아님).
- Naver Finance 재무 지표의 **공식·유료 대체 공급사** 비교.
- KRX **상용 시세 라이선스** 비용·범위 산정.
- 상용 트래픽 기준 **DART API 호출 한도** 재산정.
