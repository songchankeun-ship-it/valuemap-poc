## §3. 다음 로컬 제안 작업 (③ — 작게 구현 가능)

`ornscore-spec-coverage.md` A절에서 **이미 ③(표시·문구·소규모 컴포넌트)로 태깅된 항목만** 옮김. 데이터 산식·`stocks.json`·`direction` 무변경으로 가능한 범위. 광범위/투기적 신규 작업 없음.

1. **필터 현재 조건 자연어 한 줄 요약** — "밸류가 낮고 거래활성도가 늘어난 종목" 형태 생성. 근거 spec §7(설계서 7) 10행. Task 157의 실시간 카운트에 이어지는 표시 강화.
2. **탐색 결과 압축형 보기** — 카드/표에 이어 압축 리스트 토글. 근거 spec §7 11행·A절 6.
3. **신뢰 배지 5단계 라벨/색 풀세트 정렬** — 현재 partial → normal/delayed/limited/partial/error 풀세트 라벨·색 정렬. 근거 spec §3 6행·A절 2.
4. **산식 버전 불일치 빌드 게이트(CI 스크립트)** — 현재 런타임 `selfCheck`만 → 빌드 시 `EXPECTED_METRICS_VERSION` vs `stocks.json` 메타 불일치 시 실패. 근거 spec §3 8행·A절 3.
5. **질문형 프리셋 예상 결과 수 카드** — 프리셋 카드에 설명+조건 배지+현재 결과 수. 근거 spec §7 7행·A절 1.

> 위 5개는 전부 spec-coverage에 이미 ③으로 존재하는 항목이며, 새로 만든 제안이 아니다. 자동화 큐로 하나씩 닫기 좋은 크기.
